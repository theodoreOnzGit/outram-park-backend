# HTR-10 — R-Z zone geometry (pointer)

The dataset lives with the document it was read from, in the literature archive:

**[`crates/kovan-literature/derived/terry2005-htr10-rz-zone-geometry.md`](../../crates/kovan-literature/derived/terry2005-htr10-rz-zone-geometry.md)**

It holds the axisymmetric r-z zone partition of the HTR-10 simplified benchmark
model, hand-read by the maintainer from **Fig. 2** of Terry et al. (2005),
INL/CON-05-00852 — with its provenance, the corroboration against that paper's
Table 2, and the open-provenance path via IAEA-TECDOC-1382 part 2.

Kept beside the source document rather than here so the data cannot drift away
from its provenance. Related: [`htr10-neutronics.md`](./htr10-neutronics.md)
(Terry Table 2 dimensions), beads `op-tvmf`, `op-lhu6`, `op-5c5r`.
