Chemistry decides the fate

Fission products

Fission splits uranium into elements from across the middle of the periodic table (lesson 2). A xenon atom and a strontium atom are both “fission products”, but chemically they could hardly be more different, and that decides what each does in the fuel.

Oxygen: one more player

When a uranium atom fissions, the oxygen that was bound to it has to go somewhere, and not every fission product binds as much oxygen. Spare oxygen in a UO2 kernel can react with the carbon around it and make CO gas; a UCO kernel’s carbide takes up oxygen instead. source pending for each of these statements; lesson 25 comes back to it.

Other ways to group them

Light-water reactor source terms group fission products by how they are released in a severe accident: NUREG-1465’s eight groups (Soffer et al., 1995), Table 3.8, p. 10. TRISO-ATOPS groups them by which release model it applies (lesson 15). The three groupings overlap but are not the same.
