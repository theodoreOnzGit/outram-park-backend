84 nuclides, five groups

Fission products

In lesson 15 we lumped fission products by chemistry and volatility, and found from TRISO-ATOPS’s own diffusion coefficients that it uses exactly five classes. Here is where those classes come from: the code’s list of nuclides, each tagged with a transport group.

Predict first (we did, before running the code): every nuclide’s group and its chapter 3 diffusion class agree, with no exceptions.

Five groups

The code tracks … nuclides: … noble gases, … halogens (TRISO-ATOPS counts selenium and tellurium as halogens), … special metals (Rb, Sr, Cs, Ba, Eu), … in the silver group (Ag and Pd), and … “other”. The paper groups them by chemical similarity and by how they move through the coatings, because measured data exist for only a few of them (Stoyer et al. 2026, p. 5).

The prediction held: the group (colour) decides which diffusion class a nuclide gets. Each group then gets one release model (lesson 42). That is the lumping: 84 nuclides, five behaviours.

Within a group, nuclides still differ by half-life. A nuclide counts as short-lived if its half-life is under 20 % of the irradiation time; it then reaches a steady release-to-birth ratio (lesson 19) instead of a growing release fraction (p. 5; the port’s select_nuclides).

One disagreement between the paper and the code

The paper says strontium’s diffusivities are used for barium, yttrium and europium (p. 9). The code gives Sr’s coefficients to Sr, Ba and Eu only: yttrium falls into “other”, with the nominal 10−19 m²/s. The port reproduces upstream’s code, so this is a difference between the paper and upstream, not a porting error. It is reported, not changed.

Groups against chapter 3’s families

Chapter 3’s families (lesson 11) were by chemical state in the kernel. TRISO-ATOPS’s groups are by release behaviour, much like the LWR source-term groups of NUREG-1465 that lesson 15 showed side by side. Iodine and tellurium move with xenon here because their release could not be measured separately in the AGR tests; the paper assumes they behave like xenon (p. 8).

A typo the port does not copy

One line of upstream’s accident code tests for cadmium (Z = 48) where every other line tests for palladium (Z = 46). The port uses Ag and Pd everywhere, and keeps upstream’s cadmium test behind a flag for code-to-code comparison (release_activity’s docs).
