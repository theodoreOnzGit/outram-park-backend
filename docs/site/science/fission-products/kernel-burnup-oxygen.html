Complication 6: burnup and the oxygen balance

Fission products

Every fission replaces one uranium atom by two fission products. Over the kernel’s life they build up, and the kernel slowly becomes a different material. One quiet change: the oxygen balance. The oxygen that held the uranium is not all taken up by the fission products, so the fuel’s oxygen potential rises (lesson 11).

How more oxygen bends the clean curve

Two consequences, each source pending here: in a UO2 kernel the spare oxygen can react with the carbon of the buffer to make CO gas, which adds to the pressure inside the particle; and the oxygen potential changes how some fission products move. A UCO kernel holds some carbide that takes up the oxygen, which is the reason given for developing UCO. boon-lay fuel failure computes the oxygen released per fission for UO2, UCO and thoria; the fuel-failure chapter uses it. Link back: in the many-spheres model, D itself would change with burnup.
