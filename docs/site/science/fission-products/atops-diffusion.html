One diffusion law per group

Fission products

Lesson 8 built the Arrhenius law from hops; lesson 30 used one for every element in every layer. TRISO-ATOPS keeps far fewer: one law per group for the kernel, one for the graphite, and one for silver in SiC. Nothing for the buffer or the pyrocarbon, because in this model a failed particle has lost them (lesson 39).

D against temperature, by group

diffusion_coefficient and diffusion_coefficient_sic_ag; the shaded ranges are read from the output alone (where D stops changing as the temperature falls).

Predict first (we did, before running the code): the output is flat below 700 °C for the Cs and Sr kernel laws, below 550 °C (Cs) and 800 °C (Sr) in graphite, below about 490 °C for Ag in graphite, and never for krypton’s kernel law, silver’s kernel law or silver in SiC.

Clamped, or extrapolated

Each law was fitted over a temperature range. Below it the code does one of two things. For some laws it clamps: it uses the value at the bottom of the range. The output shows the Cs kernel law flat below … and in graphite below …; Sr below … and …; Ag in graphite below … on this 25 °C grid (490 °C in the code). For the others it extrapolates the Arrhenius law down. The prediction held.

Here the paper and the code differ. The paper says that where the temperature falls below a range’s lower bound, the nearest temperature in the range is used, to avoid extrapolating at low temperature (Stoyer et al. 2026, pp. 8–9). The code does that only for the laws above: krypton’s (also used for Xe, I, Te and Se) and silver’s are extrapolated. The port follows upstream’s code. Reported, not changed. Corrected 2026-10-22: the port still follows upstream’s code by default, and now offers the paper’s rule as a named option, atops2026paper (see “Learn more” below).

Krypton’s kernel law also switches branch at 1500 °C (the dotted line). boon-lay’s random walker switches the same values at 700 °C; which is right is gh:#974.

Everything outside the four correlations gets 10−19 m²/s, in kernel and graphite alike: the paper’s reasoning is that those elements have never been seen released from TRISO fuel (p. 9).

Where it is in the code

diffusion_coefficient is one match on the atomic number, with the clamps as max(...) on the temperature before the exponential. It is called by normal_operation_node for each node, and by integrate_diffusion_over_time in an accident (lesson 45).

Learn more advanced stuff

Why the kernel law is UO2’s

The paper notes that the kernel diffusivities are for UO2, because no data exist for uranium oxycarbide (UCO), the kernel of the MHTGR fuel it models (p. 8).

The atops2026paper option

boon-lay’s port runs upstream’s code unless asked otherwise (TrisoAtopsVariant::Upstream, the default). The option TrisoAtopsVariant::ATOPS2026PAPER runs the paper’s equations as written instead (gh:#1015). For the diffusion laws it changes two things:

  • The low-temperature clamp. Every law is held at the bottom of its range, as the paper says (pp. 8–9). That adds krypton’s kernel law (so Kr, Xe, I, Te and Se) and silver in SiC, both held below 700 °C. At 400 °C krypton’s D is then about 103 times the extrapolated value.
  • Yttrium’s group. Yttrium joins Sr, Ba and Eu and takes strontium’s diffusivities (Table 1, p. 6; p. 9), instead of the nominal 10−19 m²/s.

The paper’s own printed results were computed with upstream’s code, so the default is the one that reproduces them. The tutorial case Reproducing the TRISO-ATOPS 2026 paper’s release results shows both side by side, with the code that runs them.

Compared with chapter 4

Chapter 4’s per-layer coefficients (Jiang et al. 2023) and these (the NP-MHTGR compilation) are different data sets. They share the Kr kernel values but switch them at different temperatures (gh:#974).
