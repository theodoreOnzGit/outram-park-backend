Complication 7: conductivity falls, the kernel heats up

Fission products

Fission products and radiation damage scatter the vibrations that carry heat through UO2, so its thermal conductivity falls with burnup source pending. With the same power, a poorer conductor runs hotter inside, and a hotter kernel has a higher D everywhere.

How a hotter kernel bends the clean curve

The workspace’s UO2 conductivity, in tampines, is the fresh-fuel branch of the Virtual Test Bed HTR-PM model; its documentation says burnup is not modelled and that this is optimistic (too cool) for burnt fuel. In a TRISO kernel the temperature rise inside the kernel is tiny anyway (lesson 17), so here the bigger effect is on everything around it.
