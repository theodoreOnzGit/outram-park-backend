What the model leaves out

Fission products

boon-lay fuel failure is inspired by PANAMA: a clean-room, agentic implementation of the equations published in the PANAMA-I report (Verfondern & Nabielek, HTA-IB-03/90). It is not a port: the PANAMA source code was not available. It is a simple model on purpose. Here is everything it does, simplifies, or leaves out, drawn in one place so that the gaps are as visible as the physics.

In, simplified, out

Read from boon-lay’s fuel_failure module docs and docs/lessons/src/limitations.md, 2026-10-22.

The model’s own limits

  • Built for German TRISO over 1600–2500 °C. HTR-10’s fuel is German-lineage, so applying it is defensible, but it is an extrapolation, and two of its inputs (SiC strength and fluence) are stand-ins from the report’s HTR-Module case.
  • Thin shell only. One stress in the SiC; no thick-wall solution, no load shared with the PyC.
  • Ideal gas. The error at high gas density is not estimated.
  • Decomposition is unverified against any output of the report.
  • Grain-boundary attack is off by default, as in the report.
  • As-manufactured defects are an input (φ0); the 6×10−5 target is a named constant, never a default.
  • Not for normal-operation failure (lesson 36’s note).
  • Nothing is validated against measured failure or release data.

What nothing in the workspace models yet

  • Oxidation failure. Air or steam eating through the matrix, the PyC, the SiC and an exposed kernel: tracked as gh:#441, #443 and #444.
  • Palladium and lanthanide attack on SiC. The theory book (step 4) names sources that call palladium the fission product of greatest concern; nothing in the code models it. No open source in the corpus was read for this page: source pending here.
  • The amoeba effect: the kernel migrating up a temperature gradient through the buffer in UO2 fuel. Not modelled; source pending.
  • PyC creep, swelling, cracking and debonding, which change how the load reaches the SiC (theory book step 6).
  • A multilayer diffusion solver for release through intact layers (lesson 32).

Why say all this

A model whose gaps are hidden looks more certain than it is. Each item above is a place where a real particle can do something the model cannot, and where a number from this chapter could be wrong. The next chapter shows how TRISO-ATOPS, the code that turns all this into a source term, makes its own, larger simplifications.

Where each limit is argued

The theory book gives a justification for each simplification of the report’s chain, says which kind it is (negligible, too expensive, conservative, or no data), and marks the ones it cannot justify as open: step 7, “Why each simplification is allowed”. The finite-element model that would remove most of them is described, not built, in step 5.

Naming

“PANAMA-I” means the report and the results it prints. “boon-lay fuel failure” means the code and every number it computes. A sentence like “PANAMA gives this for HTR-10” would be wrong twice: PANAMA was never run on HTR-10, and the number is boon-lay’s.
