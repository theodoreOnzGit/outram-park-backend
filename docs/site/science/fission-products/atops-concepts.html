TRISO-ATOPS concept map

Fission products · concept walks

boon-lay carries a Rust port of INL’s TRISO-ATOPS (upstream commit de374c8). This page puts each of its concepts on one card, so a reviewer can go from an idea to the code that computes it, the test that pins it, and the number that test recorded, without reading the module first.

Each card gives the equation as the code computes it (series lengths, clamps and caps included), the upstream Python function it ports, the port function in the Code Review map, its tests, the code-to-code numbers recorded against upstream, the lessons that teach it, and a link that opens the demo in the right state. The last stage, Extensions, is boon-lay’s own and not a port.

Code-to-code agreement shows the translation is faithful to upstream. It does not show the physics is right, and none of it is validation against a measured release.

Or follow a story through the cards: Cs-137 from kernel to coolant, what an accident releases, why silver is different.
