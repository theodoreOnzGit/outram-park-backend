Free gas or bound atom?

Neutronics

The transport code holds, for hydrogen in water, two files: H-1's continuous-energy file (free gas, page 22 and 42–43) and the thermal file for H in H2O (bound atom, page 44). A neutron at some energy is about to scatter off a hydrogen nucleus. Which file speaks?

Predict first: at the energy where the thermal file ends, does the scattering cross section jump? And what about the capture cross section on either side?

The rule, in our code

  1. The thermal file belongs to a nuclide. A moderator nuclide is given its S(α,β) table when the model is built (Nuclide::with_thermal_scattering, nuclide.rs:677): H-1 gets H-in-H2O, carbon gets graphite. Everything else about that nuclide still comes from its continuous-energy file.
  2. Below the table's last energy (its cutoff: 10 eV for water, 4.9 eV for graphite here, the last energy of the file's inelastic grid, thermal.rs:789) the bound-atom cross section replaces the free-gas elastic channel and the total is rebuilt around it: σtotal = σabsorption + σinelastic + σ(n,2n) + σbound (Nuclide::xs_at_energy, nuclide.rs:3366-3376). The bound cross section is the thermal file's incoherent inelastic plus, for graphite, its coherent (Bragg) elastic; it is zero at and above the cutoff (ThermalScattering::total_xs).
  3. Capture, fission and the other reactions are untouched. They are read from the continuous-energy file at every energy, below the cutoff as above. The thermal file has none.
  4. When the neutron scatters, the code first asks the thermal table. Below the cutoff it answers: it picks elastic or inelastic in proportion to their cross sections, and returns the outgoing energy and the scattering cosine in the laboratory frame, from S(α,β) (transport_csg.rs:2397, ThermalScattering::sample). Only when it declines (the neutron is above the cutoff) does the free-gas kernel run, with its target sampling and, for a nuclide with a 0 K table, DBRC (page 43). So below the cutoff neither free-gas target sampling nor DBRC is used for that nuclide.

This is the same arrangement as OpenMC's (Romano et al., 2015), which the code ports. There the thermal table is attached to a material, not to a nuclide (material.cpp:852-867), is switched off for a neutron above its energy_max (material.cpp:866), replaces the elastic cross section and corrects the total (nuclide.cpp:835-860), and sends the share of elastic scattering that belongs to the bound table to sab_scatter (physics.cpp:726-750). OpenMC can give a table a fraction of a nuclide, so that a material holding the same isotope both bound and free works; ours has no fraction, and a model that needs both holds two nuclide entries, one with the table and one without (nuclide.rs:677). OpenMC switches off at E > energy_max; ours at E ≥ cutoff, which differ on a single point.

Which file supplies the scattering?

Both curves are decoded from the ACE files OUTRAM PARK's port wrote (page 44), at 293.6 K. The blue shading marks where the thermal file supplies the scattering and the orange where the continuous-energy file does; the dashed orange curve continues the free-gas elastic below the cutoff, where it is not used. Cross sections are per hydrogen or per carbon atom. Energy windows: a thermal window, the stretch around the cutoff, and the whole 0.001–20 eV. Axes are linear.

What the numbers show

  • Down in the thermal range the two disagree wildly. At 0.0253 eV hydrogen in water scatters with 51.7 b per hydrogen in the thermal file, where the free gas would give 30.1 b. Chemical binding raises the cross section and, above all, changes where the neutron goes afterwards (up-scattering off the molecule's motion is what builds the thermal spectrum).
  • Graphite is subtler. At 0.0253 eV the bound total is 5.04 b against 4.95 b free: a near tie in the total, though 4.56 b of it is coherent Bragg scattering, which changes the neutron's direction and not its energy. The sawtooth of Bragg edges is visible in the thermal window.
  • At the cutoff the cross section hardly jumps. For water the thermal file gives 20.5377 b just below 10 eV and the free gas 20.4606 b just above; for graphite 4.7396 b against 4.7492 b. That is the design: far above kT a bound atom scatters like a free one, and the cutoff is placed where that is true. What can change there is not the cross section but the outgoing energy and angle, which switch from the S(α,β) tables to the free-gas kernel.

So the prediction answer: at the cutoff the scattering cross section moves by a few tenths of a percent, and capture does not move at all, because it never left the continuous-energy file.

Common misconception: "S(α,β) and Doppler broadening are applied one on top of the other."

They are alternatives for the elastic scattering of a bound nuclide, split by energy. Below the cutoff the S(α,β) table is used and the broadened free-gas elastic is not (it is still tabulated in the other file, but the code replaces it). Above the cutoff the broadened free-gas elastic is used and the S(α,β) table is not.

The whole picture of the data

For one moderated nuclide the code uses, in order of energy: the thermal file (S(α,β), up to its cutoff); then the continuous-energy file, free gas with the target moving (BROADR's rate, the sampled target velocity of page 42, DBRC for a heavy resonant nuclide up to 1 keV, page 43); then the same file with the target at rest; and in the unresolved range PURR's tables (pages 18–19). Every one of those was made by a module of the NJOY port, from an ENDF evaluation or a LEAPR deck, and every one is checked against NJOY2016's own output where such a comparison exists. The transport lessons that follow use these files without opening them again.
