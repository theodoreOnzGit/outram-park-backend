Neutronics

The Adler–Adler formalism (ENDF's LRF = 4) writes each cross section as a sum of simple closed-form terms, one symmetric and one asymmetric peak shape per resonance, plus a smooth background polynomial. There is no matrix and no channel bookkeeping. It is semi-empirical:

  • The theory part. Its form comes from multi-level resonance theory: ENDF-102 calls it "the Adler form of the Kapur-Peierls formalism", "a true multilevel treatment" (Trkov et al., 2018). Reich–Moore evaluations can even be converted into it (§2.4.15).
  • The empirical part. "In actual applications the parameters are determined by fitting data and the theoretical constraints among them are lost, so that any Adler cross section can be negative" (§2.4.14.1).

So the stored numbers are no longer a level's energy, spin and partial widths. Each resonance carries a set of coefficients for total, a set for fission and a set for capture; elastic is not given at all and comes from subtraction, and "no use is made of J" (§2.2.1.3). Level-level interference is still there, but only "implicitly", in the asymmetric terms.

That is the price. The numbers are cheap to evaluate and convenient to Doppler-broaden, but they have lost their physical meaning: you cannot read a lifetime or a spin from them, or check them against nuclear physics. ENDF-102 prefers Reich–Moore because it "has less flexibility and is therefore better able to distinguish between various grades of experimental data" (§2.4.15). It is the same trade-off engineers meet with any curve fit: cheap and accurate where it was fitted, and silent about why.

Nobody here uses it. None of our 51 ENDF/B-VIII.0 evaluations gives its first resolved range as Adler–Adler. NJOY2016 still supports it (csaa) (MacFarlane et al., 2017), and so does OUTRAM PARK's port of it, but with no evaluation to run it on, that port has never been checked against one. That is why there is no curve on this page.
