Maths 5: big kicks, use the bell

Neutronics

For a really hard kick, the neutron makes hundreds of phonons. Adding up hundreds of cases (rung 3's phonon expansion, smeared on rung 4) just gives a bell curve anyway. So why not use the bell curve directly?

That is what LEAPR does. Beyond a certain kick size it stops adding up phonon cases and uses a bell curve, the same shape as the free gas of rung 2. Why that is fair, in plain words: a very hard kick is over so quickly that the atom has no time to feel its springs, so for that instant it behaves almost like a free atom. Treating a very quick, hard collision as if the atom were free is called the short-collision-time approximation.

The sum against the shortcut

Both curves from OUTRAM PARK's port of LEAPR (MacFarlane et al., 2017), Si in α-quartz at 293.6 K. Where LEAPR switches from one to the other is a numerical choice inside the code, not a physical threshold.

Big kick: the two agree, so the shortcut is safe. Small kick: they clearly don't, so LEAPR keeps adding cases there. The atom never stops being bound; the bell only works for the shape of the energy exchange at large kicks.

Conventions on these pages. β = (E′ − E)/kT is positive when the neutron gains energy; α measures the size of the kick. S is LEAPR's asymmetric scattering law (the NJOY2016 manual's script S); ENDF stores the symmetric S = eβ/2 times it (page 21).
