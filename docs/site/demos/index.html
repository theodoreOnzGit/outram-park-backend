Web demos

Run OUTRAM PARK simulations directly in your browser. Every demo computes with the workspace's own Rust code, compiled to WebAssembly; nothing runs on a server. The Monte Carlo and nuclear data demos download real ENDF/B-VIII.0 evaluations and process them in your browser first, so their first start takes a minute or more.
