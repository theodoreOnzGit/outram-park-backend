# AI Usage Statement

## Purpose

This project uses Artificial Intelligence (AI) tools to assist software development, documentation, planning, literature review, code review, refactoring, testing support, and project management.

AI tools are used as engineering assistants.

All scientific claims, numerical methods, validation results, engineering decisions, and research conclusions remain subject to human review and approval.

---

# AI Systems Used

Examples include:

- Claude Code
- Microsoft Copilot
- ChatGPT
- Gemini
- NUS AI Know

The set of tools may evolve over time.

---

# Permitted Uses

AI tools may be used for:

- software scaffolding
- code generation
- refactoring
- documentation writing
- architecture planning
- test generation
- benchmark setup
- issue triage
- literature summarization
- project management
- educational content drafting

---

# Required Human Review

AI-generated outputs SHALL NOT be accepted automatically.

All generated outputs must undergo appropriate human review.

Examples include:

- code review
- scientific review
- benchmark validation
- integration testing
- documentation review

Final responsibility lies with the human contributors.

---

# Scientific Integrity

AI tools are treated as assistants.

Scientific claims are not considered valid solely because an AI system generated them.

Scientific claims must be supported through:

- literature review
- analytical derivation
- benchmark validation
- verification and validation activities
- independent human review

---

# Restricted Inputs

The following should not be uploaded to external AI systems without appropriate authorization:

- confidential data
- restricted research data
- unpublished collaborator work
- personal data
- proprietary information subject to restrictions
- material protected by legal agreements

Contributors should follow all applicable institutional policies.

---

# Open Source Development

AI-assisted contributions are permitted.

Generated code shall be reviewed for:

- correctness
- licensing compatibility
- security
- maintainability
- scientific accuracy

---

# Publication Disclosure

Where AI tools are used substantially in research-related activities, appropriate disclosure should be provided in publications.

Example wording:

> Portions of software scaffolding, documentation generation, code review assistance, and software engineering support were aided by generative AI systems. Scientific interpretation, validation, verification, and final acceptance of all outputs remained under human control.

---

# Responsibility

AI systems assist contributors.

AI systems are not authors, reviewers, maintainers, or decision-makers.

Human contributors remain responsible for:

- scientific integrity
- code quality
- verification and validation
- publication decisions
- project governance
