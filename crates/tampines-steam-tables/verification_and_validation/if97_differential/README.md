# IF97 differential comparison: provenance and regeneration (gh:#1346)

Results and interpretation: `RESULTS.md`. Predictions written before the run: `PREDICTIONS.md`.
Test that pins the results: `../../tests/if97_vs_coolprop_if97.rs`.

## Reference data (what is committed, and where it came from)

| file | what | source, version, licence, date accessed |
|---|---|---|
| `coolprop_if97_reference.csv.gz` | 8 052 rows: the inputs and the CoolProp IF97 outputs | produced by `coolprop_if97_driver.cpp` from CoolProp/IF97 `IF97.h` **v2.4.0, git commit `138ec05fd64c60167515f6a4f5448cdd19466d27`** (<https://github.com/CoolProp/IF97>, MIT licence), cloned 2026-11-13; g++ 13.3.0, glibc 2.39, x86-64, `-O2 -std=c++17` (no `-ffast-math`, no `-march=native`) |
| `rusteam_reference.csv.gz` | the rust-steam outputs for the same inputs | produced by `rusteam_driver/` from marciorvneto/rusteam **commit `2b1f74dbed98bcfeaae2d68fa8ebd9d5b4e080b8`, v0.2.0** (<https://github.com/marciorvneto/rusteam>, MIT licence, license text reproduced in the crate README), cloned 2026-11-13; kJ/kg outputs multiplied by 1000.0 in the driver |
| `coolprop_if97_driver.cpp` | input-grid generator and CoolProp driver | written for this issue, AGPL-3.0-only like the crate |
| `rusteam_driver/` | rust-steam driver | same; `Cargo.toml.scratch` is deliberately not named `Cargo.toml` so cargo does not see a nested package |

The rows are numerical outputs of the published IAPWS-IF97 equations; no IAPWS table text is
reproduced. Inputs are grids generated by rule, not data from any facility.

Cross-checks that are **not** committed: `pip install CoolProp` 8.0.0 (`PropsSI` with
`IF97::Water`), used to confirm one dome value, and the source packages `iapws` 1.5.5 and
`seuif97` 2.3.8, used to decide which of two disagreeing coefficient values is the published one
(the three sources agree on every corrected coefficient listed in `RESULTS.md`).

Files are gzip members written with `gzip -n` (10-byte header, no name or mtime); the test
inflates them with `miniz_oxide` (pure Rust, already a workspace dependency).

## Regenerating

```bash
git clone https://github.com/CoolProp/IF97.git if97 && git -C if97 checkout 138ec05fd64c60167515f6a4f5448cdd19466d27
git clone https://github.com/marciorvneto/rusteam.git rusteam && git -C rusteam checkout 2b1f74dbed98bcfeaae2d68fa8ebd9d5b4e080b8
g++ -O2 -std=c++17 -Iif97 coolprop_if97_driver.cpp -o drv && ./drv > ref.csv
# rust-steam driver, in a scratch directory OUTSIDE the workspace
mkdir -p rsd/src && cp rusteam_driver/Cargo.toml.scratch rsd/Cargo.toml && cp rusteam_driver/src/main.rs rsd/src/
#   (edit rust-steam's path in rsd/Cargo.toml to the clone above)
(cd rsd && cargo run --release) < ref.csv > rus.csv
gzip -9n -c ref.csv > coolprop_if97_reference.csv.gz
gzip -9n -c rus.csv > rusteam_reference.csv.gz
```

A different libm or compiler may move the last digits of the CoolProp column; the test pins
this crate's results against the committed files, so regenerate and re-pin together.
