# Code walk: the four-factor formula, from the example to `SixFactors`

Tutorial rung 2 (GitHub #524), step 6. Generated by `kovan-cli code-walk`
(#523); see `one_collision_with_carbon.md` for how the blocks are regenerated
and what "filled by hand" means.

`examples/ugraphite_four_factor.rs` builds the homogeneous mixture
(`examples/common/ugraphite_common.rs`), calls `run_keff_reactor_physics`,
which runs the ordinary CSG power iteration with a combined track-length tally
(`run_keff_csg_reactor_physics` → `run_keff_csg_par` → `transport_history_vr`
per history), and then assembles the factors with `assemble_six_factors`. The
example re-assembles them once more with the thermal absorption split by
nuclide, because in a homogeneous mixture the library's material-based "fuel"
is everything (see the example's module docs).
