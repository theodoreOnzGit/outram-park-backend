# Code walk: resonances and the capture branch (resonance escape `p`)

Tutorial rung 2 (GitHub #524), step 5. Generated by `kovan-cli code-walk`
(#523); see `one_collision_with_carbon.md` for how the blocks are regenerated
and what "filled by hand" means.

**There is no function that computes `p`.** Resonance escape is what is left
after the loop below has run: a neutron flies a distance set by `Σ_t(E)`
(large on a resonance peak, so flights are short there), picks the nuclide it
hit in proportion to `N_i σ_t,i(E)`, then picks the reaction by where a uniform
`ξ·σ_t` lands among the partial cross sections. A capture is the branch
`else if xi < x.absorption { break 'history; }` of `transport_history_vr`
(filled by hand: an `if`, not a function).

The cross sections come from the workspace's own reconstruction of the ENDF
resonance parameters (RECONR + BROADR port in `njoy-outram-park-fork`), read
by `Nuclide::xs_at_energy`; in U-238's unresolved range (20–149 keV) the
`_urr` variants apply a probability-table band, drawn once per energy and
shared by the flight, the nuclide choice and the reaction (OpenMC's
`calculate_urr_xs`, GitHub #407).
