## The scatter fork

Three branches, chosen per collision (filled by hand from the `else` scatter
branch of `transport_history_vr`, `crates/outram-mc-libs/src/physics/transport_csg.rs`):

1. **Bound atom, S(α,β):** `nuc.sample_thermal(e, seed)` returns
   `Some((e_out, mu_lab))` when the nuclide carries a thermal table and `e` is
   below its cutoff (the tape's `E_max` since #459). H-1 in LCT-008's water
   takes this branch below a few eV. The outgoing direction is
   `rotate_direction(u, mu_lab, seed)`.
2. **Free gas:** otherwise, below 400 kT, `free_gas_elastic_scatter_dbrc`
   samples the target nucleus's thermal motion (with DBRC's rejection for
   resonant nuclides below 1 keV), so the neutron can gain energy.
3. **Target at rest:** above 400 kT the same function reduces to two-body
   kinematics off a stationary nucleus; that is where α and ξ of step 1 live.

**There is no function that computes ξ or the ~18 collisions.** They emerge
from repeating branch 3 (and then 1) collision after collision.
