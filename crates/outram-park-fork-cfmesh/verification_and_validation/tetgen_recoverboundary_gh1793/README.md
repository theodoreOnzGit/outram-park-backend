# TetGen port, stage 4: boundary recovery against an instrumented upstream (gh:#1793)

> AI-assisted draft, untrusted until human-reviewed (`RESPONSIBLE_USE.md`).
> For education, research and V&V only.

Epic gh:#1789. Stage 4 ports what TetGen 1.6.0's `tetrahedralize()` runs
under `-p` (no `-D`) after `meshsurface()`: `recoverboundary()` and
everything it reaches with default switches and with `-Y`. The public entry
is `tetgen::tetrahedralize_plc(&PlcInput, &Behavior)`, which runs up to and
including recovery (the exterior is still meshed: `carveholes` is stage 5).

- **`src/tetgen/flip.rs`**: the tetrahedron-subface and tetrahedron-segment
  links (`tsbond`, `tspivot`, `stpivot`, `tssbond1`, `sstbond1`,
  `tsspivot1`, `sstpivot1`, ...) with upstream's `tet2subpool` /
  `tet2segpool` arrays; `flip23`, `flip32`, `flip41`, `flip31`, `flipnm`,
  `flipnm_post` (its `abtets` overloading as the `AbTet` enum),
  `tri_edge_test` / `tri_edge_tail` / `tri_edge_2d`, `planelineint`,
  `interiorangle`, `tetprismvol`, `is_collinear_at`, `is_segment`,
  `valid_constrained_f23` / `f32`, `checkflipeligibility`,
  `removeedgebyflips`, `removefacebyflips`.
- **`src/tetgen/recover.rs`**: `makesegmentendpointsmap`, `finddirection`,
  `getedge`, `recoveredgebyflips` (with the full search), `recoversegments`,
  `recoverfacebyflips`, `recoversubfaces`, `recoverboundary` (the random
  stack orders, the flip-link-level rounds, the duplicated-facet repair, the
  Steiner suppression rounds), `scoutsegment`, `scoutsubface` and the dump.
- **`src/tetgen/steiner.rs`**: `insertpoint` (Bowyer-Watson with the
  cavity validated against the recovered boundary, `INSTAR`, the
  `refineflag` 4 / 8 checks of boundary recovery), `insertpoint_abort`,
  `create_a_shorter_edge`, `linelineint`, `smoothpoint` (volume objective),
  `add_steinerpt_in_schoenhardtpoly`, `add_steinerpt_in_segment`,
  `add_steinerpt_to_recover_edge`, `recoversubfaces`' two Steiner branches,
  `getvertexstar`, `reduceedgesatvertex`, `removevertexbyflips`,
  `sremovevertex`, `lawsonflip3d` and `recoverdelaunay` (stage 5's routine,
  which `recoverboundary` calls after each Steiner point).
- **`src/tetgen/surface.rs`**: `sinsertvertex_full`, `sinsertvertex` with
  its `splitseg` and `INSTAR` branches (the old entry calls it with no
  segment; stage 3's 13 cases are unchanged).

**Not reached by `recoverboundary`, so not ported:** the CDT path (`-D`):
`constraineddelaunay`, `delaunizesegments`, `getsteinerptonsegment`,
`constrainedfacets`, `formregion`, `scoutcrossedge`, `formcavity`,
`delaunizecavity`, `fillcavity`, `carvecavity`, `restorecavity`,
`flipcertify`, `flipinsertfacet`, `insertpoint_cdt`, `refineregion`
(upstream calls them only from `constraineddelaunay`). `scoutsegment` and
`scoutsubface` are CDT routines too; they are small, ported, and reached by
the unit test `scout_routines_find_edges_and_faces`, not by recovery.

**Branches not ported** (never set by boundary recovery): `insertpoint`'s
weighted tests (`-w`), encroachment rejection (`rejflag`), insertion radii,
mesh sizes (`-m`), `chkencflag` queues, `smlenflag`; `smoothpoint`'s
aspect-ratio and dihedral objectives (`get_tetqual`);
`checkflipeligibility`'s `remove_large_angle` (mesh improvement);
`create_a_shorter_edge`'s facet maps (built only by `-D` / `-q`: in
recovery upstream reads a `NULL` list there; the port returns
`InternalError`); element attributes and volume bounds.

## Methodology

- **Reference.** TetGen 1.6.0 (libigl/tetgen `e05aca7df74e`), `tetgen.cxx`
  built with g++ 13.3.0 `-O2 -ffp-contract=off`, `predicates.cxx` `-O0`,
  x86_64, glibc 2.39, with `recoverboundary_dump.patch` applied to the
  pristine sources (it contains stage 3's `dump_meshsurface` too). The
  patch adds `dump_recoverboundary()`, which `tetrahedralize()` calls right
  after `recoverboundary()` returns when `TG_DUMP4=<file>` is set (then
  exits), and 55 call counters `tg_reach[]` (reset at the start of
  `recoverboundary`, written to `TG_REACH=<file>`): 38 routines and 17
  branches (indices in the patch). Without the variables the instrumented
  build writes the same `example.1.{node,ele,face,edge}` as the unmodified
  binary under `-pq` (checked; only the `# Generated by` comments differ).
- **Reference runs** are `tetgen -p` and `tetgen -pY`, **without `-Q`**:
  upstream puts a few `terminatetetgen` calls inside its
  `if (!b->quiet && !b->nowarning)` warning blocks, so `-Q` changes the
  control flow; the port follows the default and keeps the warnings in
  `TetgenMesh::warnings`. `-Y` reaches recovery through `meshsurface`
  (coplanar facets are not merged), which makes several cases need flips
  and Steiner points `-p` does not.
- **The dump** (text, one record per line, pool order, dead slots
  included): every point (mark, type, flag bits, coordinates as bits, a
  duplicate's parent, `point2tet`, `point2sh`); `dummypoint`; every subface
  (vertices, marker, flags, facet index, neighbour, segment and tetrahedron
  links with versions); every subsegment (vertices, marker, flags, segment
  index, links, whether `sh[6]` is set, tetrahedron link); every
  tetrahedron (vertices, neighbours with versions, the marker word with
  every flag and the element counter, the six segment and four subface
  links, `-` where upstream's `tet[8]` / `tet[9]` is `NULL`); the dead-item
  stacks; `recentsh`, `recenttet`; the `randomnation` seed; `insegments`;
  `st_segref_count`, `st_facref_count`, `st_volref_count`, `steinerleft`;
  `flip23count`, `flip32count`, `flip41count`, `flip22count`,
  `flip31count`; `fliplinklevel`, `autofliplinklevel`, the duplicated and
  skipped facet counts; the sizes of `subvertstack`, `subsegstack`,
  `subfacstack` and `flippool`; the next glibc `rand()`.
- **Port.** `TetgenMesh::dump_recoverboundary()` writes the same format;
  `TetgenMesh::reach` holds the same 55 counters.
- **Pass criterion.** For every case and switch, the two dumps are equal
  line for line (exact text) **and** the two reach arrays are equal. No
  tolerance.
- **Test.** `tests/tetgen_recoverboundary_vs_upstream.rs` reads only
  committed files: stage 3's inputs (`test_data/tetgen_meshsurface/`) and
  `test_data/tetgen_recoverboundary/` (gzip, 1.9 MB: six new inputs, 38
  dumps, 38 reach files).
- **Upstream-free check** (`recovered_boundary_is_in_the_mesh`): on every
  case and switch, every tetrahedron is positively oriented (exact
  `orient3d < 0`); every subsegment is a mesh edge linked from every
  tetrahedron around it, and each input segment's subsegments form a chain
  between its two endpoints; every subface is a face of the mesh, bonded
  (both sides) to tetrahedra that link it back.

### Cases

The 13 stage 3 inputs, and six new ones made to need Steiner points and
deep flips (written once by a scratch script; the committed `.poly` files
are the inputs):

| case | what it exercises |
|---|---|
| `schoenhardt` | a Schönhardt prism (triangle twisted by 30°, side quads split on the reflex diagonals): no tetrahedralisation without a Steiner point; `add_steinerpt_in_schoenhardtpoly` + `smoothpoint` + `insertpoint(INSTAR)` |
| `thin_slab` | a 1 x 1 x 0.005 plate, jittered 8 x 8 grids top and bottom: deep `flipnm` link recursion, 4-to-4 flips |
| `facet_wall`, `facet_wall2` | a box with an internal wall at z = 0.5 and 20 / 60 free vertices 1e-3 / 1e-2 above and below it: facet Steiner points (on a missing subface edge and inside a face), removed again by 4-to-1 / 6-to-2 flips with `flip31` |
| `skew_segments` | five interior segments 0.01 apart in z, at different angles, with 20 free vertices near them: segment Steiner points (`add_steinerpt_in_segment`, `linelineint`), removed by `removevertexbyflips` (2n-to-n) + `sremovevertex`; one Schönhardt point |
| `skew_points` | eight such segments 1e-3 apart with 30 free vertices: the full-search flips of `recoveredgebyflips` |

`example.poly` needs **no** Steiner point in recovery: the ~210 Steiner
points it gets with `-q` come from Delaunay refinement (stage 6), not from
`recoverboundary` (checked: `tetgen -pV` reports 44 (0) segments and 52 (0)
subfaces recovered, 0 Steiner points).

### Regenerating

```bash
S=<scratch>/tetgen_stage4; mkdir -p $S/src $S/cases
cp <tetgen-clone>/{tetgen.cxx,tetgen.h,predicates.cxx} $S/src/
cd $S/src && patch -p1 < <repo>/crates/outram-park-fork-cfmesh/verification_and_validation/tetgen_recoverboundary_gh1793/recoverboundary_dump.patch
g++ -O0 -c predicates.cxx -o predicates.o
g++ -O2 -ffp-contract=off -o tetgen_dump tetgen.cxx predicates.o -lm
cd $S/cases
for f in <repo>/crates/outram-park-fork-cfmesh/test_data/tetgen_meshsurface/*.{poly,smesh,edge}.gz \
         <repo>/crates/outram-park-fork-cfmesh/test_data/tetgen_recoverboundary/*.poly.gz; do
  gunzip -c $f > $(basename $f .gz); done
for c in example unit_box box_hole box_edges comb_prism grid_box jitter_soup slit_box fin_box \
  pipe fuel_channel pebble sphere schoenhardt thin_slab facet_wall facet_wall2 skew_segments skew_points; do
  f=$c.poly; [ -f $f ] || f=$c.smesh
  for sw in p pY; do TG_DUMP4=$c.$sw.dump TG_REACH=$c.$sw.reach ../src/tetgen_dump -$sw $f > /dev/null; done
done
T=<repo>/crates/outram-park-fork-cfmesh/test_data/tetgen_recoverboundary
for f in *.dump *.reach; do gzip -n -9 -c $f > $T/$f.gz; done
cargo test --release -p outram-park-fork-cfmesh --test tetgen_recoverboundary_vs_upstream -- --nocapture
```

Regeneration is deterministic (rerunning gave byte-identical dumps). The
reach indices are listed by the `tg_reach[...]++` lines of the patch.

Summed over the 38 runs, every ported routine is reached except
`scoutsegment` and `scoutsubface` (CDT routines; reached by the unit test
only). Branches **not** reached by any committed case: `removevertexbyflips`'
4-to-1 (`INTETRAHEDRON`) and shift-into-volume branches, duplicated facets
(an overlapping-facet input made upstream segfault and was dropped),
`add_steinerpt_in_schoenhardtpoly`'s `splitsliverflag` path,
`lawsonflip3d`'s non-convex hull branch (`nonconvex` is set by
`carveholes`, stage 5) and the `unflip` branches of `flipnm` /
`flipnm_post` (only mesh improvement sets `unflip`). They are ported line
for line but unverified.

**The comparison can fail.** Making `finddirection` take the other move in
one `randomnation(2)` choice (`hori > 0, rori > 0, lori <= 0`) breaks
`box_hole -p` at dump line 52 (`s 3 ... t54.9` against `t16.4`); tried and
reverted. `the_comparison_can_fail` pins that `fliplinklevelinc = 2`
changes the `fuel_channel -pY` dump.

**Defects found and fixed while porting** (each was a dump difference):
`recoverdelaunay` re-queued its unflipped faces with the handle from before
`getedge` / `removeedgebyflips` updated it (upstream works on
`bfarray[i]` in place); stage 2's `locate` tested "the tet has a subface
array" where upstream tests the entry at the face (`issubface`; no effect
before stage 4, struck through and corrected in `delaunay.rs`).

## What stage 5 (gh:#1794: `carveholes`, `suppresssteinerpoints`, `recoverdelaunay`) has and needs

Ready: the recovered mesh with every subface and subsegment bonded to its
tetrahedra (pinned by this test), the Steiner points and their counters,
`subvertstack`, `recoverdelaunay` and `lawsonflip3d` (ported here, called
after each Steiner point; stage 5 calls them once more after
`carveholes`), `removevertexbyflips`, `getvertexstar`, `smoothpoint`
(volume objective), `getedge`, `flip31`, `sremovevertex`,
`later_unflip_queue`.

Missing: `carveholes` (with the region attributes and the `nonconvex`
flag, which turns on `lawsonflip3d`'s hull branch, ported but unverified),
`suppresssteinerpoints` and `suppressbdrysteinerpoint`,
`smoothpoint`'s other objectives (`get_tetqual`), the output routines
(`outelements` for a PLC, `outsubfaces`, `outsubsegments`). Note:
upstream deletes `skipped_segment_list` at the end of `recoverboundary`
without resetting the pointer; nothing in 1.6.0 reads it afterwards (the
port keeps the list).
