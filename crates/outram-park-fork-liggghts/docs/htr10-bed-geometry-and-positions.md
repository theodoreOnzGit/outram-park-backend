# HTR-10 bed — geometry, pebble positions, and how to plot them

A V&V companion document: everything needed to **draw** the HTR-10 DEM beds in
3-D, without reading any Rust. The geometry is stated in full below, every
committed set of pebble positions is listed, and a ready-to-run `matplotlib`
script is given at the end.

This exists because the HTR-10 results in
[`verification-and-validation.md`](./verification-and-validation.md) are
reported as numbers — solid fractions, per-particle displacements, `g(r)` — and
a number cannot show you that the bed slumped into the conus, that the free
surface is a cone, or that a recirculation batch landed where it was meant to.
Several real defects in this work were only obvious once someone looked at
positions: pebbles stacking into 50 towers, and a bed re-inserted 0.04 m inside
itself.

> **Scope.** These are offline simulation outputs for education, research and
> verification. Nothing here is operational reactor data, and nothing here is
> validated against a physical HTR-10 bed — see the V&V document's
> "What is still NOT validated".

---

## 1. Geometry

All dimensions SI, axis of symmetry along `z`, origin **at the conus inlet**
(the bottom of the cylindrical core). Sourced from
`docs/reactor-scoping/htr10-neutronics.md` (IAEA-TECDOC-1382 design point).

| Quantity | Symbol | Value | Note |
|---|---|---|---|
| core radius | `R_core` | **0.90 m** | `D/d = 30` |
| pebble diameter | `d` | **0.06 m** | `r = 0.03 m` |
| pebble density | `ρ` | **1730 kg/m³** | nuclear graphite |
| conus height | `H_cone` | **0.36946 m** | `z = 0` down to `z = −0.36946` |
| discharge tube radius | `R_tube` | **0.25 m** | |
| discharge tube length | `L_tube` | **0.25 m** | **shortened** from the real 6.1 m — see below |
| valve plane | `z_valve` | **−0.61946 m** | `= −(H_cone + L_tube)` |
| published filling fraction | `f` | **0.61** | recorded as *quoted*, not measured |
| published mean bed height | | **1.97 m** | |

**The tube is deliberately short.** The real HTR-10 discharge tube is ~6.1 m.
Its length is irrelevant to defuelling — what matters is that pebbles leave the
conus and rest on the valve — and a full-length tube only costs fall time. At
0.25 m it still holds ~250 pebbles against a 50-pebble extraction batch.

### 1.1 Surfaces

Three surfaces confine the bed. Two are analytic primitives; the conus and tube
are a **triangulated mesh read by both codes**,
`reference-data/liggghts/htr10_discharge.stl` (480 facets, inward normals),
generated by `make_htr10_discharge_stl.sh` beside it.

| Surface | Definition |
|---|---|
| core barrel | cylinder, `x² + y² = R_core²`, for `z ≥ 0` |
| conus | truncated cone, radius `R_core` at `z = 0` linearly to `R_tube` at `z = −H_cone` |
| discharge tube | cylinder, `x² + y² = R_tube²`, for `−H_cone ≥ z ≥ −(H_cone + L_tube)` |
| defuelling valve | plane `z = z_valve`, pebbles rest on it until extracted |

The conus wall makes **29.6° with the horizontal**
(`atan(H_cone / (R_core − R_tube)) = atan(0.36946 / 0.65)`), a shallow hopper,
which is what the published dimensions give. The mesh normals were checked
empirically rather than assumed: a sample facet normal is
`(−0.494, 0.013, 0.869)` — inward **and** upward, as a funnel wall must be.

The **flat-floor** cases (the original settling runs) replace all three of the
above with a single plane at `z = 0`.

### 1.2 Contact parameters

| Parameter | Value | Note |
|---|---|---|
| Young's modulus `E` | `5e8 Pa` | softened from graphite's ~9 GPa; see V&V § 4.7 |
| Poisson ratio `ν` | 0.2 | |
| restitution `e` | 0.5 | |
| sliding friction `µ` | **swept**: 0.1 and 0.4 | see the ablation, V&V |
| rolling friction `µ_r` | **swept**: 0.0 and 0.1 | CDT model |
| timestep `dt` | `3.5e-5 s` | 11.7 % of the Rayleigh time at this `E` |

## 2. Pebble position files

All live in `reference-data/liggghts/`. Layout is one row per pebble,
`id,x,y,z,vx,vy,vz`, SI, with a header row. Coordinates are full `double`
precision.

| File | Code | Geometry | What it is |
|---|---|---|---|
| `htr10_init.csv` | LIGGGHTS | flat floor | post-insertion, before settling |
| `htr10_settled.csv` | LIGGGHTS | flat floor | settled — the **common starting point** for everything below |
| `htr10_settled_ours.csv` | this port | flat floor | settled independently from the same start |
| `htr10_conus_t{2000,6000,12000,20000}_liggghts.csv` | LIGGGHTS | conus | slump trajectory checkpoints |
| `htr10_conus_settled_liggghts.csv` | LIGGGHTS | conus | final slumped state |
| `htr10_conus_presettled_<label>.csv` | this port | conus | slumped and settled, at one friction setting |
| `htr10_recirc_<label>_bed.csv` | this port | conus | after slow recirculation, at one friction setting |

`<label>` encodes the friction setting: `mu40_mur10` is `µ = 0.4, µ_r = 0.1`;
`mu10_mur00` is `µ = 0.1, µ_r = 0.0`; and so on.

Two derived datasets accompany them:

| File | What it is |
|---|---|
| `htr10_phi_vs_step_<label>.csv` | **packing fraction vs DEM step** through the conus slump, sampled every 500 steps: `phase, step, phi_bulk, phi_whole_core, surface_height, ke_per_pebble_over_edrop` |
| `htr10_recirc_<label>.csv` | per-**batch** history: `phase, batch, step, extracted, n, phi_bulk, phi_whole_core, surface_height, ke_per_pebble_over_edrop, elapsed_s` |
| `htr10_rdf.csv` | `g(r)` vs pair separation for every bed above, tidy: `case, mu, mu_r, stage, n_pebbles, n_centres, r_m, r_over_d, g, coordination, counts` |

**Why there are two `φ` series and not one.** They answer different questions at
different resolutions. The per-batch file asks *what did each recirculation
batch do* — one row per 50 pebbles exchanged. The `phi_vs_step` file asks *how
did the bed evolve*, and it exists because **almost all of the movement in `φ`
happens before the first batch**: draining the flat-floor bed into the conus
takes `φ` from 0.5646 to 0.5770 over 14 000–16 000 steps, and a per-batch series
records that entire transient as a single number at `batch 0`.

A note on `step` in the per-batch file: it counts DEM steps from the start of
*that run*, so when the pre-settle was served from its cache it begins at 0 at
the first batch. The `phi_vs_step` companion always runs from the flat-floor bed,
so its `step` is absolute.

## 3. Plotting it

The script below draws any of the position files against the geometry: a
vertical mid-plane slice of the pebbles (so the interior is visible rather than
just the outer shell), plus the barrel, conus and tube as wireframes.

> Requires only `numpy` and `matplotlib`. It reads the committed CSVs directly
> and needs nothing from this workspace built.
>
> **All three scripts below were executed before this document was committed**
> (numpy 2.5.3, matplotlib 3.11.2, `Agg` backend), not written and left
> unchecked. The first renders 3 723 of the 27 554 pebbles of
> `htr10_conus_settled_liggghts.csv` in a `|y| < 3r` slab, against the barrel,
> conus, tube and valve.

```python
import numpy as np
import matplotlib.pyplot as plt

# ---- geometry (section 1) -------------------------------------------------
R_CORE, R_TUBE = 0.90, 0.25
H_CONE, L_TUBE = 0.36946, 0.25
Z_VALVE = -(H_CONE + L_TUBE)
R_P = 0.03

CSV = "reference-data/liggghts/htr10_conus_settled_liggghts.csv"
SLAB = 3 * R_P          # half-thickness of the visible slice; None for all

data = np.genfromtxt(CSV, delimiter=",", names=True)
x, y, z = data["x"], data["y"], data["z"]
if SLAB is not None:                      # cut a slab so the interior shows
    keep = np.abs(y) < SLAB
    x, y, z = x[keep], y[keep], z[keep]

fig = plt.figure(figsize=(7, 10))
ax = fig.add_subplot(111, projection="3d")

# pebbles as points sized to the pebble diameter
ax.scatter(x, y, z, s=6, c=z, cmap="viridis", depthshade=True, linewidths=0)

# ---- wall wireframes ------------------------------------------------------
th = np.linspace(0, 2 * np.pi, 121)
z_top = z.max() if len(z) else 2.0

def ring(r, zz, **kw):
    ax.plot(r * np.cos(th), r * np.sin(th), np.full_like(th, zz), **kw)

style = dict(color="0.35", lw=0.8)
for zz in np.linspace(0.0, z_top, 6):     # barrel
    ring(R_CORE, zz, **style)
for t in np.linspace(0, 1, 5):            # conus: R_CORE -> R_TUBE
    ring(R_CORE + t * (R_TUBE - R_CORE), -t * H_CONE, **style)
for zz in np.linspace(-H_CONE, Z_VALVE, 3):   # discharge tube
    ring(R_TUBE, zz, **style)
ring(R_TUBE, Z_VALVE, color="crimson", lw=1.6)   # the defuelling valve

for a in np.linspace(0, 2 * np.pi, 8, endpoint=False):   # vertical generators
    ax.plot([R_CORE * np.cos(a), R_CORE * np.cos(a), R_TUBE * np.cos(a),
             R_TUBE * np.cos(a)],
            [R_CORE * np.sin(a), R_CORE * np.sin(a), R_TUBE * np.sin(a),
             R_TUBE * np.sin(a)],
            [z_top, 0.0, -H_CONE, Z_VALVE], **style)

ax.set_xlabel("x [m]"); ax.set_ylabel("y [m]"); ax.set_zlabel("z [m]")
ax.set_box_aspect((2 * R_CORE, 2 * R_CORE, z_top - Z_VALVE))
ax.set_title(f"HTR-10 bed — {CSV.split('/')[-1]}  ({len(x)} pebbles shown)")
plt.tight_layout()
plt.show()
```

### Plotting the recirculation history

```python
import numpy as np, matplotlib.pyplot as plt

fig, ax = plt.subplots(figsize=(7, 4))
for label in ["mu40_mur10", "mu40_mur00", "mu10_mur10", "mu10_mur00"]:
    d = np.genfromtxt(f"reference-data/liggghts/htr10_recirc_{label}.csv",
                      delimiter=",", names=True)
    ax.plot(d["extracted"], d["phi_whole_core"], marker="o", ms=3, label=label)
ax.axhline(0.61, color="crimson", ls="--", label="published 0.61 (quoted)")
ax.set_xlabel("pebbles recirculated"); ax.set_ylabel(r"$\phi$ whole-core")
ax.legend(); plt.tight_layout(); plt.show()
```

### Plotting packing fraction vs step

```python
import numpy as np, matplotlib.pyplot as plt

fig, ax = plt.subplots(figsize=(7, 4))
for label in ["mu10_mur00", "mu10_mur10", "mu40_mur00", "mu40_mur10"]:
    try:
        d = np.genfromtxt(f"reference-data/liggghts/htr10_phi_vs_step_{label}.csv",
                          delimiter=",", names=True, dtype=None, encoding="utf-8")
    except OSError:
        continue
    ax.plot(d["step"], d["phi_whole_core"], lw=1.2, label=label)
ax.axhline(0.61, color="crimson", ls="--", lw=1, label="published 0.61 (quoted)")
ax.set_xlabel("DEM step"); ax.set_ylabel(r"$\phi$ whole-core")
ax.set_title("HTR-10: packing fraction through the conus slump")
ax.legend(fontsize=8); plt.tight_layout(); plt.show()
```

The steep early rise is the bed draining out of its flat-floored shape into the
funnel; the plateau is the settled bed, and where each curve plateaus is the
friction ablation's result.

### Plotting `g(r)`

```python
import numpy as np, matplotlib.pyplot as plt

d = np.genfromtxt("reference-data/liggghts/htr10_rdf.csv", delimiter=",",
                  names=True, dtype=None, encoding="utf-8")
fig, ax = plt.subplots(figsize=(7, 4))
for case in np.unique(d["case"]):
    m = d["case"] == case
    ax.plot(d["r_over_d"][m], d["g"][m], lw=1, label=case)
for x, lab in [(1.0, "$d$"), (np.sqrt(2), r"$\sqrt{2}d$ (FCC)"),
               (np.sqrt(3), r"$\sqrt{3}d$"), (2.0, "$2d$")]:
    ax.axvline(x, color="0.8", lw=0.8)
    ax.text(x, ax.get_ylim()[1] * 0.95, lab, fontsize=7, rotation=90)
ax.set_xlabel("$r/d$"); ax.set_ylabel("$g(r)$"); ax.legend(fontsize=7)
plt.tight_layout(); plt.show()
```

The three vertical guides are the diagnostic: peaks at `√3 d` and `2 d` are the
signature of a **random** packing, while a peak at `√2 d` would indicate
FCC/HCP **crystallisation**. See V&V § 3.2.
