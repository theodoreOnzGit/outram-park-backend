## Regenerating

```bash
# 1. CoolProp, from source, at the commit this crate ports
mkdir CoolProp && cd CoolProp && git init . && git remote add origin https://github.com/CoolProp/CoolProp.git
git fetch --depth 1 origin 0e67fe74b30a2fe9526af9bc64ea026a96f56ebf && git checkout FETCH_HEAD && cd ..
# (clone the dependencies above into deps/, then)
cmake -S CoolProp -B build -DCMAKE_BUILD_TYPE=Release -DCOOLPROP_STATIC_LIBRARY=ON \
  -DCMAKE_CXX_FLAGS="-O2 -ffp-contract=off" -DCMAKE_C_FLAGS="-O2 -ffp-contract=off" \
  -DCPM_Eigen_SOURCE=deps/eigen -DCPM_msgpack-c_SOURCE=deps/msgpack -DCPM_nlohmann_json_SOURCE=deps/json \
  -DCPM_valijson_SOURCE=deps/valijson -DCPM_IF97_SOURCE=deps/IF97 -DCPM_REFPROP_headers_SOURCE=deps/refprop \
  -DCPM_boost_headers_SOURCE=deps/boost -DCPM_multicomplex_SOURCE=deps/multicomplex -DCPM_fmt_SOURCE=deps/fmt
cmake --build build -j2            # about 15 minutes on 2 cores
# 2. the driver
g++ -O2 -std=c++17 -ffp-contract=off -DCOOLPROP_NO_DEPRECATED_HEADER_WARNINGS -DFMT_HEADER_ONLY \
  -ICoolProp/include -ICoolProp/src -Ideps/fmt/include -Ideps/json/include -Ideps/eigen -Ideps/boost \
  -Ideps/multicomplex/include -Ideps/IF97 -Ideps/msgpack/include \
  coolprop_driver.cpp build/libCoolProp.a -ldl -lpthread -o drv
./drv fluids.txt > full.csv                    # 1.7 s; sha256 above
sh make_subset.sh full.csv | gzip -9n > coolprop_subset.csv.gz
# 3. analyse the full file (not committed) and print the tables
COOLPROP_FULL_REF=full.csv COOLPROP_REPORT_OUT=report.csv \
  cargo test --release -p outram-park-fork-coolprop --test coolprop_differential full_reference_report
# 4. re-pin deliberately (record old and new in RESULTS.md first)
COOLPROP_WRITE_PINS=pins.csv cargo test --release -p outram-park-fork-coolprop --test coolprop_differential subset_reference
gzip -9n -c pins.csv > pins.csv.gz
```

A different libm or compiler may move the last digits of the CoolProp column; the pins hold bit-identical
counts that may only rise and worst-difference bounds that may only fall, so regenerate and re-pin
together, deliberately, and say why.
