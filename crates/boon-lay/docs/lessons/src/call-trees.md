# Call-tree appendices

> **Research, education and V&V only** ([`RESPONSIBLE_USE.md`](https://github.com/theodoreOnzGit/outram-park-backend/blob/@@COMMIT@@/RESPONSIBLE_USE.md)).

One exhaustive call tree per lesson: everything the lesson's entry point
reaches inside the workspace, standard library and dependencies filtered
out, each function expanded once (a later call to it is a back-reference).
They double as a map of the crate's architecture. Every tree is generated by
rust-analyzer through `kovan-cli code-walk` and regenerated by
`kovan-cli code-walk-check --update`; a hop the tool cannot follow (a trait
method, a closure, a function pointer) is marked as such, never guessed.

Generated 2026-10-04 at `develop` atop `5f6a5157b0`. Of the marks in these
trees, 189 are `UNRESOLVED(closure)`: calls of a closure value defined in
the calling function (the `rate` helper in `AccidentHistory::step`, the
point and row helpers in `triso_cell_slice`, and the like), whose bodies
are on the same lines the tree links to. The other 9 are `UNRESOLVED(other)`,
standard-library calls such as `clone` that rust-analyzer does not attribute
to a workspace function. None of them hides a workspace function the tree
should have shown, as far as reading the linked lines shows; that reading
was done for the rung 5 and rung 2 entries and not for every one.

The lessons themselves are in the tutorial book,
[TRISO-ATOPS and fuel failure, one rung at a time](../../tutorials/triso-atops/intro.html).
