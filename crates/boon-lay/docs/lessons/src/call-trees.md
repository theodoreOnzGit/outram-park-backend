`kovan-cli code-walk-check --update`; a hop the tool cannot follow (a trait
method, a closure, a function pointer) is marked as such, never guessed.

trees, 189 are `UNRESOLVED(closure)`: calls of a closure value defined in
the calling function (the `rate` helper in `AccidentHistory::step`, the

are on the same lines the tree links to. The other 9 are `UNRESOLVED(other)`,
standard-library calls such as `clone` that rust-analyzer does not attribute
to a workspace function. None of them hides a workspace function the tree
should have shown, as far as reading the linked lines shows; that reading
was done for the rung 5 and rung 2 entries and not for every one.
