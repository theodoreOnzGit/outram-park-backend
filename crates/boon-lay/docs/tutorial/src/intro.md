> **This site always tracks the `develop` branch.** It is rebuilt on every
> push, and every code link points at the exact commit it was built from,
> [`@@COMMIT_SHORT@@`](https://github.com/theodoreOnzGit/outram-park-backend/commit/@@COMMIT@@)
> (@@BUILD_DATE@@).

> **Review status: first draft, 2026-10-04, AI-assisted, not yet reviewed by a
> human.** Every claim links to the code or the record it rests on, so it can
> be checked.

These lessons follow **one atom born in a TRISO fuel particle**, and ask the
questions a curious reader would ask, in order: what is the particle, when
does the atom decay, how does it move, what holds it back, when does the
particle break, what do air and steam do, and how does the atom reach the
coolant. Each answer uses the real code of OUTRAM PARK's
[`boon-lay`](https://github.com/theodoreOnzGit/outram-park-backend/tree/@@COMMIT@@/crates/boon-lay)
crate. Each step has the same shape:

1. a question;
2. the shortest answer;
3. the formula;
4. a small illustration of exactly that idea;
5. the **code walk**: how the program gets from its entry point down to the
   lines that do it, in words and as generated by rust-analyzer;
6. the measured check, where there is one, and a plain statement where
   there is none;
7. a **predict** prompt that sets up the next question.

## Numbers

Every number on these pages is quoted from a record in the repository, with
the file, the date and the commit, or comes from a run made for these pages
(2026-10-04, `develop` atop `5e802df3a4`, `--release`, one thread on one core),
which is then recorded beside the code. When a re-run moved a number, the old
one is struck through and the new one is the one to quote. A comparison with
an exact solution, another code or a report's printed output is
**verification**; only a comparison with a measured experiment is
**validation**, and almost nothing in this track has one.

## The names

- **PANAMA-I** is a 1990 Jülich report and its printed results. **boon-lay
  fuel failure** is this crate's own code, written from that report's
  equations. They are never interchangeable.
- **TRISO-ATOPS** is INL's MIT-licensed Python code; `triso_atops_fork` is a
  Rust port of it, verified against it code to code.
